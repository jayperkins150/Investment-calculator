# Investment Calculator

An investment calculator that helps users estimate the future value of investments based on contributions and growth rates.

## Features

- Calculate projected investment growth
- Annual contribution support
- Interest rate calculations
- User-friendly interface
- Instant updates

## Technologies Used

- React
- JavaScript
- CSS

## Getting Started

### Clone the repository

```bash
git clone https://github.com/jayperkins150/Investment-calculator.git
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```
